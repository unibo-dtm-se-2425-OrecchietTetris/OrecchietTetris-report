# Self-evaluation

## Mariagrazia Colonna

Within the OrecchietTetris project, I contributed to the verification and validation of the system architecture and focused my development efforts on the audio service and the leaderboard repository. 

One of the main technical challenges I encountered concerned the implementation of the leaderboard, particularly the need to correctly arrange the displayed elements and keep the interface responsive as new records were added over time. 

Another significant issue emerged while working on the audio service, where the initial solution generated by Claude Code caused the current song to restart whenever playback was resumed after a pause. To address this limitation, I redesigned the functionality so that pausing effectively sets the volume to zero instead of stopping the music entirely. Although this approach allows the track to continue playing in the background, it provides a smoother and more enjoyable listening experience when the audio is restored. 

From a teamwork perspective, one of the main difficulties was establishing an effective collaboration rhythm, defining when tasks should start and be completed, and developing a shared mindset focused on contributing to the overall completion of the project. 

Looking back, the experience highlighted the importance of tools such as Git and GitHub and their potential to become a natural part of future software projects. It also offered valuable opportunities to improve my coding, code comprehension and code review skills, while providing a first practical experience with generative AI tools and the development of prompting techniques aimed at obtaining more effective and accurate results.

## Mirko de Cillis

In this project I was responsible for the design and the architecture of the system, together with the initial configuration of the repository, in particular GitHub Actions, Poetry and Dependabot. On the code side I concentrated mainly on the model, and since I have more experience in software development, I was also responsible for the code review before accepting the pull requests to ensure consistency and quality across the project.

Throughout the implementation phase, I used Claude Code both to produce an initial draft of some components and as support for solving coding issues. I had in any case to carefully review its output to be sure about the quality, and in some cases I had to do some optimizations, such as removing duplicated code or restructuring modules into smaller and more maintainable components.

Regarding the teamwork, in the initial phase of the development I supported the other members in framing correctly the tasks they would carry out, so that they could proceed more efficiently, and during the development I helped the team to solve some bugs that emerged during implementation.

Overall, the creation of OrecchietTetris permitted me to apply the fundamentals of the design of a software system, of its components and of the way they interact, while also navigating the best practices for an optimal configuration of the code, with the goal of keeping it easily maintainable and always updated. The use of Claude Code allowed me to discover its potential and its limits, giving me a concrete perception of its effectiveness in writing code: I consider it an excellent tool for accelerating development, combined with careful human supervision in order to guarantee its quality and to be fully conscious of what has been written.

## Lorenza Pennisi
My contribution to the project focused on the verification and validation of the system architecture, the setup and management of Trello used to organize and distribute tasks among team members, and the development of the view layer of the application.

During the project implementation, I used Claude Code for an initial code draft and as a support for fixing it and for solving technical issues, but the most significant challenge that I faced was the continuous UI refactoring process. I spent considerable time improving the usability of the interface, moving buttons and settings multiple times, adjusting layouts and refining color choices until the navigation experience became intuitive and visually coherent.

From a teamwork perspective, I collaborated with the team members, regularly discussing about problems and exchanging feedback to improve both design and implementation decisions. As a team we also reviewed and analyzed every relevant block of code generated by Claude Code, to understand its general meaning and purpose.

From a personal perspective, this project has represented an opportunity of learning and growth, because it allowed me to acquire and strengthen competences in writing, understanding and reviewing code, and to gain familiarity with the use of tools such as Git, GitHub and Visual Studio Code, which I had already used for other exams but that in this occasion we explored more in depth. In addition, the use of Generative AI tools, which are increasingly relevant in professional environments, was a way to speed up and optimize the development of the project, refining my ability in writing effective prompts to obtain the desired output. Moreover, the project gave me the opportunity to understand how to work inside a team, improving collaboration and coordination, while also enhancing my -problem-solving skills.
